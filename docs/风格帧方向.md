# 电影化风格方向：Signal / Form

这套画面参考了目标视频的叙事方法，但没有复制它的金色竖条、文字海或具体镜头。原创母题是一个发光的菱形“信号种子”：念头从一个点出发，寻找结构，经历失真，最终发光，并在黑场中留下余像。

## 五段视觉链

1. **点火 Ignition**：近乎全黑，只建立一个发光种子和一个问题。
2. **漂移 Drift**：轨迹与等高线被种子吸引，表现“寻找形状”。
3. **断裂 Fracture**：画面第一次出现洋红色，文字与几何体发生错位。
4. **显现 Emergence**：暖色只在高潮释放，结构像地平线一样发光。
5. **余像 Afterimage**：重新回到黑场，用一句回答收束。

## 设计约束

- 画幅固定为 `1920 × 804`，接近 2.39:1 电影宽画幅。
- 每帧只有一个视觉中心，不使用卡片、面板或仪表盘式排版。
- 青色负责“信号”，洋红负责“冲突”，珊瑚暖色只在高潮出现。
- 中文主标题使用衬线体，英文信息使用高字距无衬线体。
- 噪点、暗角和细边框只提供质感，不能抢夺主体。
- 下一阶段的动画必须从这些静态帧生长，不另起一套 UI 风格。
