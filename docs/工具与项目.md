# Claude 视频工具与项目选型

调研时间：2026-09-30。

## 最近火的是什么

主流玩法是 **Claude Code + Remotion**：

1. 你用自然语言写需求。
2. Claude Code 把需求拆成脚本、场景和动画，生成 React/TypeScript。
3. Remotion Studio 实时预览，人通过对话继续修改。
4. Remotion 把 React 组件逐帧渲染为 MP4。
5. 需要时接入 TTS、图像/视频模型、字幕、音乐和 FFmpeg。

这更像“AI 写了一个可重复渲染的视频工程”，而不是一次性的文生视频。优势是文字准确、修改可控、可版本管理、可批量生成。

## 工具地图

| 方案 | 适合做什么 | 建议 |
| --- | --- | --- |
| [Remotion](https://github.com/remotion-dev/remotion) | React 程序化视频、宣传片、字幕、数据动画 | 本项目的主线 |
| [Remotion Agent Skills](https://github.com/remotion-dev/skills) | 让 Claude Code/Codex 掌握正确的 Remotion 写法 | 已安装到本项目 |
| [Remotion Claude Code Plugin](https://github.com/remotion-dev/claude-code-plugin) | Claude Code 专用插件 | 只用 Claude Code 时可再装；本项目已有 Skills，不是必需 |
| [Manim Community](https://github.com/ManimCommunity/manim) | 数学、算法、科普推导动画 | 遇到 3Blue1Brown 风格再引入 |
| [Motion Canvas](https://github.com/motion-canvas/motion-canvas) | TypeScript 动画、解说视频 | 可选替代，当前先不引入 |
| [local-video-use](https://github.com/SafeMantella/local-video-use) | 本地访谈/口播粗剪、Whisper 转录、FFmpeg 合成 | 以后要剪真人素材时再单独建工程 |
| FFmpeg | 压缩、转码、拼接、抽帧、混音 | 本机已安装 8.1 |

## 建议的迭代顺序

1. 先用纯图形 + 文字完成 10–20 秒样片，跑通预览和修改循环。
2. 加入你自己的颜色、字体、Logo，做成品牌模板。
3. 再接 TTS 配音和字幕，不要一开始就上全自动流水线。
4. 需要写实镜头时，用视频模型生成小段素材，由 Remotion 统一排序、字幕、转场和品牌视觉。
5. 内容稳定后再做“一句话批量出片”，避免把不稳定的创意流程过早自动化。
