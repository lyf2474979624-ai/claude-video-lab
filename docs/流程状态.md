# 制作流程状态

更新时间：2026-09-30

用户纠正后的重点：**画面本身的运动、镜头变化、音效与动作同步**。旧版只验证了文件合成与发送；静态画面推拉不能视为运动设计达标。旁白、真人配音、解释性字幕不是本片必需项。

当前 V2《成形》采用 Three.js / R3F，以帧时间驱动 15,500 个粒子的位置形变、旋转光环、飞散碎片、波动曲线和镜头；声音由共享时间点生成，无人声。连续视频与独立静帧交叉检查用于发现着色器时间未更新等问题。

## 结论

本片需要：**动作设计 → 逐帧画面 → 同步音效 → 连续播放检查 → 渲染交付**。配音、字幕和写实生成素材均可省。技术检查与用户审美反馈是两种验收，不能用“文件成功导出”代替后者。
