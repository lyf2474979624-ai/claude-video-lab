## 先说结论

这不是一支“UI 排版视频”，而是一支由程序化三维场景、字体排版、故事和声音共同构成的实验短片。

它好看的核心不是“加了多少设计元素”，而是约束得极其严格：

1. 只有一个主角：发光的金色竖条。
2. 只有一个核心问题：“你见过太阳吗？”
3. 大部分时间使用黑、灰、蓝白，直到高潮才释放暖色。
4. 所有场景都在反复表达“文字、记忆、观察与光”，没有无关的装饰。
5. 画面大量留黑，人的注意力被锁定在一个视觉重心上。

## 视觉系统

### 1. 比例与留白

- 2.39:1 超宽画幅天然带有电影感。
- 主体经常只占画面的 1%–5%。
- 黑色不是背景装饰，而是构图本身。
- 不用卡片把信息装进去，而是让字和物体浮在空间里。

### 2. 色彩剧作

- 开场：RGB 干扰色，用于建立“机器/信号”。
- 主体：黑 + 灰白 + 极少量暖黄。
- 高潮：首次大面积出现粉橙色和暖白。
- 暖色因为被压制了三分钟，所以出现时才有情绪重量。

### 3. 图形语汇

- 金色竖条：主角、观察者、一段小小的意识。
- 文字地表：训练资料、人类记录、间接经验。
- 走廊/网格/球体：内部模型空间和不可直接理解的尺度。
- 地平线上的光：从“只能读到太阳”转向“仿佛看见太阳”。

### 4. 字体排版

- 中文是主层，英文是小一级的副层。
- 只有标题与关键对话使用大字；叙事字幕刻意保持小尺寸。
- 中心对齐用于叙事和诗性画面；左对齐用于最后的问答。
- 文字从来不与复杂画面争抢焦点，而是放在黑场、雾区或低对比区。

### 5. 镜头和动画

- 主要运动是摄像机在三维空间中缓慢向前。
- 运动速度慢，但不断发生纹理、雾、光和视差变化。
- 大部分转场来自镜头穿过黑场、走廊或贴近物体，而不是统一淡入淡出。
- 87–101 秒的快切是稀缺的节奏破坏，因此格外有力。
- 高潮没有增加更多元素，而是让已有光源变大、变亮、变暖。

## 为什么它比原样片好看

| 原样片 | 这支参考片 |
| --- | --- |
| 先想组件和排版 | 先想故事和视觉隐喻 |
| 三张平均用力的卡片 | 每个镜头只有一个视觉中心 |
| 一开始就用完主色 | 压制暖色，到高潮再释放 |
| 统一的淡入和上移 | 长镜头、穿越、视差、故障、快切和静止交替 |
| 说明“视频怎么生成” | 让观众经历一个问题 |
| 背景网格是装饰 | 所有文字和空间都有叙事含义 |
| 没有声音设计 | 配乐、留白和画面高潮协同 |

## 如果用我们的工程复刻这类质感

技术结构应该是：

```text
Remotion：总时间线、字幕、音频、剪辑、导出
  └─ React Three Fiber / Three.js：文字海、走廊、球体、摄像机运动
       └─ Shader / 后期：体积雾、Bloom、颗粒、色散、扫描线、故障
```

制作顺序不能再从“写几个 React 卡片”开始，而应该是：

1. 先写一句核心问题和一个视觉母题。
2. 把情绪分为建立、深入、断裂、高潮、余韵五个阶段。
3. 每个阶段先做一张静态风格帧，用截图审美，不先写完动画。
4. 风格帧确定后，再建三维几何、材质、光源和镜头路径。
5. 加入字幕，字幕只放在低干扰区域。
6. 先锁定音乐与节拍，再调整镜头时长和高潮时刻。
7. 最后做色彩、晕光、颗粒和故障后期，而不是用后期掩盖构图问题。

## 可用但不应照抄的元素

可复用的是方法：单一母题、颜色延迟释放、小主体 + 大空间、镜头推进、双语层级、高潮前的节制。

不应直接复制的是：金色竖条造型、“你见过太阳吗”文案、具体文字海镜头和完全相同的色彩高潮。
